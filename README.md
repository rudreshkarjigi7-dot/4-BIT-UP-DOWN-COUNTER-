# 4-BIT UP & DOWN COUNTER
Designed and implemented a 4-bit Up/Down Counter using Verilog HDL as a digital VLSI design project. The counter was developed to perform both upward and downward counting operations based on a control signal. The design includes clock and reset functionality for reliable sequential operation.

Performed RTL coding, functional simulation, waveform analysis, and verification of the counter. Verified different counting sequences, control conditions, reset behavior, and clock transitions to ensure correct functionality. The RTL design was analyzed to understand the synthesized hardware structure and sequential logic implementation.

This project provided practical experience in Verilog HDL, RTL design, digital logic, sequential circuits, simulation, functional verification, and basic VLSI front-end design methodology.
